# Mobile App QA Test Plan

## Project Name

DemoShop Mobile App QA Testing

## Objective

The objective of this test plan is to verify the core functionality of a mock mobile shopping application and document test cases, defects, and test execution summary in a structured QA format.

## Application Type

Mobile e-commerce application

## Testing Type

- Functional Testing
- UI Testing
- Regression Testing
- Negative Testing
- Usability Testing

## Scope of Testing

### In Scope

- Login functionality
- Product search
- Product details page
- Add to cart
- Checkout flow
- Logout functionality
- Basic UI validation

### Out of Scope

- Payment gateway integration
- Performance testing
- Security testing
- Backend API testing
- Real device compatibility testing

## Test Environment

| Item | Details |
|---|---|
| Device Type | Android Mobile |
| OS Version | Android 13 |
| App Type | Mock Mobile App |
| Network | Wi-Fi |
| Testing Method | Manual Testing |

## Entry Criteria

- Application is accessible
- Core screens are available
- Test cases are prepared
- Test data is available

## Exit Criteria

- All planned test cases are executed
- Critical and high-priority defects are documented
- Test summary report is prepared
